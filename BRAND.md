# 🟢 BrandOS — Marca Mãe

**BrandOS** é a holding/umbrella brand que une os 3 negócios:

```
BrandOS (Marca Mãe)
├── Negócio Simples (SaaS + Mentoria)
├── CliniSales (Agência + Lab)
└── PowerHouse (Marketplace Agentes IA)
```

## 🎨 Identidade Visual

**Logo:** Interface futurista neon verde
- Padrão geométrico (pixel/modular)
- Círculo com borda industrial
- Vibe: Tech, AI-first, controle total
- Cores: Verde neon (#00FF00 ou similar) + Preto + Cinza

**Paleta:**
- Verde neon (primary - accent)
- Preto profundo (background)
- Cinza (neutrals)
- Branco (contrast)

**Tipografia:**
- Headings: Geist Bold (futurista)
- Body: Geist Regular (legível)
- Mono: JetBrains Mono (tech feel)

**Tom de voz:**
- Direto, sem BS
- Tech-savvy mas acessível
- Empoderador (você pode fazer isso)
- Confiante mas humilde
