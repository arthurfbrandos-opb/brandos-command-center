## 2. NEGÓCIO SIMPLES 📚

### Status
- **Lançado:** início fevereiro 2026
- **Base:** 100 mentorados (da base própria de Arthur)
- **Mercado:** ainda não lançado (phase 1 = validar com base própria)

### O que é
**Mentoria + SaaS + Comunidade** para donos de agência que querem:
- Escalar faturamento
- Usar IA + processos
- Ser pequeno, lucrativo, sem 200 pessoas

### 3 Pilares

#### **Foundation OS** 🏗️
Estruturação do modelo de negócio:
- Nicho, ICP, proposta de valor
- Diferenciação + posicionamento
- Método único (mecanismo de diferença)
- Esteira de produtos

#### **Sales OS** 💰
Sistema de vendas (Método NSP):
- **N** = Funil marketing (captação)
- **S** = Funil prospecção (IA + ativo)
- **P** = Processo comercial (humano + IA)

Resultado esperado: 30-40%+ conversion

Envolve: SDR, sales farming, social selling, hunter IA, closer, vendas

#### **Delivery OS** ⚙️
Simplificar entregas com IA:
- Onboarding eficiente
- Gestão de carteira (health da conta)
- Tech para não virar CLT
- Automação + IA nos processos

### Estrutura Operacional

**SaaS:** "Jarvis" da empresa
- Coração operacional
- Ferramenta que o mentorado usa todo dia
- Integra Foundation + Sales + Delivery

**Comunidade Discord:**
- Tech talks (ferramentas, IA, novidades)
- Cumbucar semanal (live + discussion)
- Book club (mentalidade)
- Apoio em mentalidade/gestão

### Diferencial vs Level Up
| | Level Up (2024) | Negócio Simples (2026) |
|---|---|---|
| Formato | Educação em grupo | SaaS + comunidade |
| Duração | <1 ano | Em construção |
| Mentorados | ~100 | 100 (fase 1) |
| Ferramenta | Educação/cursos | SaaS (Jarvis) |
| Foco | Aulas/treinamento | Implementação + tech |

## 3. POWERHOUSE ⚡

### Status
- **Estágio:** Embrionário (não é prioridade agora, mas tá mapeado)
- **Tipo:** Marketplace/plataforma de agentes IA

### O que é
Fornecedora de agentes operacionais + serviços para agências.

**Sistema:** Coins/créditos
- Cliente contrata serviço
- Paga com coins (menor que contratação tradicional)
- Agente IA entrega resultado

### Oferece (Agentes/Serviços)
- Designer IA
- Webdesigner IA
- SDR IA
- Prospector/Hunter IA
- Assistente IA (administrativo)
- Gestor de tráfego
- _(Mais no futuro)_

### Clientes Alvo
1. **CliniSales** (interno)
   - Usa os agentes pra simplificar entrega
   - Prova de conceito interna

2. **Mentorados Negócio Simples**
   - Usam como "terceirização operacional"
   - Em vez de contratar, aluga agente

### Modelo de Negócio
Exemplo: designer IA
- Custo: R$X por projeto (coins)
- Tradicional: um designer + salário (CLT) ou R$5-10k freelancer
- PowerHouse: R$500-2k por projeto via IA
- **Margem:** Arthur vende coins; IA entrega

### Papel Estratégico
**BACKEND OPERACIONAL**

Faz os 3 rodarem:
- CliniSales entrega com menos gente
- Mentorados do Negócio Simples não precisam contratar
- PowerHouse vira receita recorrente/por projeto

### Por que agora é embrionário
1. CliniSales e Negócio Simples ainda tão em phase de validação
2. Precisa de integração com Negócio Simples SaaS
3. Arthur quer focar nas duas estrelas antes
